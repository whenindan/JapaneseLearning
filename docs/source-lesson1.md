## 3. Ngữ pháp (NGỮ PHÁP BÀI 1) — "Xin chào, mình là Minh"

Theme: **Giới thiệu bản thân một cách đơn giản.**

Can-do goals (the lesson covers five structures; only #1 is in the export):
1. Câu khẳng định — *Tôi là Minh.*
2. Câu phủ định — *Tôi không phải là học sinh.*
3. Câu hỏi xác nhận thông tin — *Nam là người Nhật phải không?*
4. Nhấn mạnh vị ngữ giống nhau với trợ từ "cũng" — *Tôi là học sinh. Nam cũng là học sinh.*
5. Trợ từ "của" (thuộc về nơi nào đó) — *Tôi là học sinh của NKDV.*

### Structure 1 — N1 は N2 です。 (Tôi là Minh)

- **Ý nghĩa:** Danh từ N1 là Danh từ N2
- **Cách dùng:** Nói về thông tin của N1
- N1 = chủ ngữ (chủ đề của câu)
- N2 = vị ngữ (tên, quốc tịch, tuổi, nghề nghiệp, …)
- です: cuối câu khẳng định, biểu thị lịch sự với người nghe
- は: trợ từ, **đọc là わ** (dịch: thì, là, ở)

Examples by N2 type:
| N2 type | Example |
|---|---|
| Tên riêng | わたし は ミン です。 / わたし は カイン です。 |
| Nghề nghiệp | わたし は 学生 です。 / わたし は いしゃ です。 |
| Quốc tịch | わたし は ベトナム人 です。 |
| Tuổi | Nam さん は 18さい です。 |

Practice items (picture prompts):
| Prompt | Sentence |
|---|---|
| Tôi là giáo viên | わたし は きょうし です。 |
| Anh (học sinh) | アインさん は がくせい です。 |
| Trang (nhân viên ngân hàng) | チャンさん は ぎんこういん です。 |
| Tôi 20 tuổi | わたし は 20さい です。 |
| Chị Tanaka (người Nhật) | たなかさん は にほんじん です。 |
| Kiên (nhân viên công ty) | キエンさん は かいしゃいん です。 |
| Hoa 28 tuổi | ホアさん は 28さい です。 |

### Can-do: tự giới thiệu

```
はじめまして。
わたし は カイン です。      (Tên)
19さいです。                 (Tuổi)
がくせいです。               (Nghề nghiệp)
ベトナムじんです。           (Quốc tịch)
どうぞよろしく おねがいします。
```
